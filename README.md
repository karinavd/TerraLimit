# DB Updater
This script uses [weatherapi.com](https://www.weatherapi.com/) as provider for air data, [UNEP GEMS/Water Global Freshwater Quality Archive](https://zenodo.org/records/18459694) as provider for water data. <br>
Therefore, you need to set some configuration before launching this script. <br>
It requires weather api key and connection string: <br>
<img width="705" height="241" alt="image" src="https://github.com/user-attachments/assets/340bfe54-9193-4efa-a952-7c32581f21f9" /> <br>
Api key example: 422c48t88917090d0v4m4555d22265e43. <br>
Connection string example: Host=your_host;Port=your_port;Database=your_database_name;Username=your_username;Password=your_password.<br>
Then launch this script with "dotnet run" command in terminal and wait until its finished.
